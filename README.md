# College Notes Sharing App

## Project Overview
This project is a low-fidelity wireframe design for a mobile application that helps college students find and share academic notes easily.

## Problem Statement
Students often struggle to find organized study materials before exams.

## User Needs
- Easy access to notes
- Search by subject
- Download PDFs quickly
- Upload notes easily

## Features
- User Login
- Search Notes
- Download PDFs
- Upload Notes

## Design Process
1. User Research
2. User Persona
3. User Flow
4. Low-Fidelity Wireframes

- Figma
- GitHub
- VS Code
