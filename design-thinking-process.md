# Design Thinking Process

## 1. Empathize
Students struggle to find academic notes quickly during exam preparation.

## 2. Define
There is a need for a centralized mobile application where students can search and share notes easily.

## 3. Ideate
Planned features such as note search, PDF download, and note upload functionality.

## 4. Prototype
Created low-fidelity wireframes using Figma.

## 5. Test
Focused on creating a simple and easy-to-understand user flow.
